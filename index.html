chaos-shorts

chaos-shorts は、運営者が自分の YouTube チャンネル（日本語版「ぺらこ AIで遊ぶ人」、英語版「AI Auto Drama」）に、AIが制作する連続ショートドラマを毎日自動で投稿するための個人用ツールです。一般の利用者向けのサービスではありません。

▶ YouTube API サービスを使用しています
本ツールは YouTube API サービスを使用しています。利用には YouTube 利用規約が適用されます。データの取り扱いはプライバシーポリシーおよび Google プライバシーポリシーをご覧ください。

本ツールは YouTube Data API を利用して、運営者自身のチャンネルへの動画投稿、投稿した動画への投票案内コメントの投稿、投稿した動画に寄せられた公開コメントからの投票（A/B）の集計を行います。

Each episode ends with a choice (A or B). Viewers vote in the comments, and the AI writes the next episode based on the winning choice.
