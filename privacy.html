プライバシーポリシー

最終更新日: 2026年10月30日

取得する情報

本ツールは、運営者本人が許可した Google アカウントについてのみ、YouTube Data API を通じて次の操作を行います。

  • 運営者のチャンネル（日本語版・英語版の2チャンネル。いずれも運営者が所有）への動画のアップロード
  • 本ツールが投稿した動画への、投票を案内するコメントの投稿
  • 本ツールが投稿した動画に寄せられた公開コメントの読み取り（「A」「B」の投票を数えるため）
  • 本ツールが投稿した動画の再生数・高評価数・コメント数の取得

利用目的

取得した情報は、動画の投稿、次回の展開を決める投票の集計、今後の動画内容の改善のためにのみ使用します。

第三者への提供

取得した情報を第三者に販売・提供することはありません。

YouTube API サービスの利用

本ツールは YouTube API サービスを使用しています。本ツールを利用することで、YouTube 利用規約に同意したものとみなされます。Google によるデータの取り扱いについては Google プライバシーポリシーをご確認ください。

Google API の利用について

本ツールによる Google API から受け取った情報の使用は、Google API Services User Data Policy（Limited Use 要件を含む）に従います。YouTube の利用には YouTube 利用規約 と Google プライバシーポリシー が適用されます。

データの保存と削除

コメントの本文、投稿者の名前やチャンネル ID などの個人を特定できる情報は、投票を数える処理の中で一時的に参照するだけで、保存・共有しません。本ツールが保存するのは、本ツールが投稿した動画の動画 ID・タイトル・再生数・高評価数・コメント数と、各話の投票結果（A と B の票数）のみで、運営者の非公開リポジトリに保管します。統計値は取得から30日以内に更新または削除します。保存データの削除を希望する場合は、下記の連絡先までご連絡ください。7日以内に削除します。また、アクセス許可を取り消した場合、本ツールは以後データを取得せず、保存済みのデータは30日以内に削除します。

アクセスの取り消し

Google セキュリティ設定ページから、いつでも本ツールへのアクセスを取り消せます。
